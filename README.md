# Petualangan I/O — Media Pembelajaran Kelas X

Website React + Vite bertema pastel pink, cream, sage, dan ilustrasi chibi/kawaii untuk materi Manajemen Sistem Input/Output.

## Menjalankan
1. Pastikan Node.js terpasang.
2. Buka folder proyek di VS Code.
3. Jalankan `npm install`.
4. Jalankan `npm run dev`.
5. Buka alamat lokal yang ditampilkan Vite.

## Build
Jalankan `npm run build`.

## Struktur
- `src/App.jsx`: seluruh konten, navigasi, game, simulasi, dan interaksi.
- `src/styles.css`: desain responsif, warna pastel, dan tipografi.
- `src/main.jsx`: entry point React.

Font memakai Google Fonts: Nunito (teks), Playfair Display (judul), dan Pacifico (aksen script). Jika ingin memakai font Amoresa/Gistesy berlisensi milikmu, letakkan file font `.woff2` di `public/fonts` lalu ubah `@font-face` di CSS.

Catatan pembelajaran: website adalah pendamping LKPD, bukan pemberi jawaban otomatis. Siswa tetap berdiskusi dan menuliskan jawaban dengan kata-kata sendiri.
